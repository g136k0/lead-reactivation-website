# Lead Recovery landing page

A conversion-focused Next.js landing page for a lead reactivation and follow-up service.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

## Before launch

- Add `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` in Vercel before accepting consultation requests.
- Add genuine case studies when available.
- Add privacy and cookie notices appropriate to the markets you target.

The project is ready for GitHub and Vercel once the production build succeeds.
